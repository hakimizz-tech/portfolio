# Portfolio

## Description
Personal portfolio website built with React, TypeScript, and Vite to present projects, skills, and contact information in a clean single-page layout.

## Installation
1. Install dependencies:
   ```bash
   npm install
   ```

## Run
1. Start the development server:
   ```bash
   npm run dev
   ```
2. Create a production build:
   ```bash
   npm run build
   ```
3. Preview the production build:
   ```bash
   npm run preview
   ```

## Usage
Open the app in your browser and navigate through the portfolio sections. Update portfolio content in `src/data/portfolioData.ts`.
